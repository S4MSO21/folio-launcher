# Folio

Leitor de e-books estilo Kindle para tablets Android antigos (API 25), em Java nativo, sem Gradle.
Launcher/quiosque com biblioteca, leitor EPUB/PDF/TXT/FB2/CBZ/HTML, metas de leitura, Folio Transfer (Wi-Fi) e Paper Motion.

Compilar: `powershell -ExecutionPolicy Bypass -File build.ps1` (precisa do Android SDK em C:\Android\Sdk e JDK 17).
